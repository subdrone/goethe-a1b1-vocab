# Goethe A1–B1 德语词汇学习台

把歌德学院德语词汇表做成一个**可交互的单文件 HTML 学习工具**，支持 A1 / A2 / B1 分级、红/黄/绿三色单选分类、可折叠侧栏、中文释义与例句。

## 直接使用

双击打开根目录的 **`A1_Wortliste.html`** 即可（纯前端、无需服务器、数据已内嵌）。

> 打开后若行为与说明不符，多半是浏览器缓存了旧版：请在页面按 **Ctrl + Shift + R** 强制刷新。
> 左上角标题旁的版本徽章（如 `v6`）可用来确认当前版本。

## 功能

- **分级**：全部 / A1 / A2 / B1，共 4772 条，去重后唯一词 3095。
- **三色分类**：每个单词左侧红/黄/绿三个单选圆圈（未选也显示颜色），点一次选中、再点取消。
- **跨级别统一**：同一个词在 A1/A2/B1 共享颜色（按词 `mk` 记录）。
- **默认不隐藏**：标记颜色后，词仍留在主屏。
- **「隐藏已分类」= 一次性批量动作（不是开关）**：按一下把**此刻**已标色的词批量移出主屏；之后新标色的词仍留在主屏，直到再次按下。
- **「显示全部（N）」**：把移出主屏的已分类词全部放回；点顶部「全部」或任意颜色筛选同样会放回。
- **隐藏低级已学词**：默认开启，隐藏 A1/A2 已出现过的重复词。
- 名词性别以底色区分（der 蓝 / die 粉 / das 黄）；强变化动词显示变位形式；例句置于右侧，一屏尽量多显示。
- **专题词组表**：按主题分组的词组视图。
- **持久化**：标记存于浏览器 `localStorage`（键 `goetheA1.marks.v4`），并提供**导出 / 导入 JSON 备份**。

## 数据

| 项目 | 说明 |

## 目录结构

```
A1_Wortliste.html      # 交付产物：单文件、数据内嵌
src/
  template.html        # HTML / CSS / JS 模板（含 __DATA__ 占位符）—— 改源码改这里
  build_data.py        # 组装 src/data.json
  build_html.py        # 把 data.json 注入模板，生成根目录的 A1_Wortliste.html
  parse_a2b1.py        # 解析 A2 词条与 B1 CSV
  translate.py         # DeepSeek 批量翻译（需环境变量 DEEPSEEK_API_KEY）
  forms_data.py        # A1 动词/形容词变位映射
  data.json            # 构建中间产物（条目数据）
```

## 重新构建

```bash
cd src
python3 build_html.py      # 读取 data.json + template.html → 生成 ../A1_Wortliste.html
```
